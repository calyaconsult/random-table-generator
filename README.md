# Random Traffic Table Generator

This project generates a sample traffic data table and displays it in a web browser.

## Data Generation

*   To generate new sample data, run the Node.js script from the project's root directory:
    ```bash
    node index.js
    ```
*   This script will create or overwrite a file named `generated-monthly-data.json` in the root directory.
*   The `generated-monthly-data.json` file contains sample data arrays for the current system month and the two preceding months.

## Displaying Data

*   Open the `index.html` file in a web browser to view the data.
*   The webpage, through `script.js`, loads data from `generated-monthly-data.json`.
*   You can select which month's data to display using the dropdown menu located above the table. The table defaults to showing the data for the most recent month available in the JSON file.

## Code Structure

*   `index.js`: Node.js script responsible for generating the random traffic data for three months.
*   `script.js`: Frontend JavaScript that fetches `generated-monthly-data.json`, populates the month selection dropdown, and dynamically renders the selected month's data into the HTML table.
*   `index.html`: The main HTML file that structures the webpage and includes the table and month selector.
*   `style.css`: Contains CSS rules for styling the page elements, including the table and its cells.
*   `generated-monthly-data.json`: The JSON file where the data generated by `index.js` is stored. This is the primary data source for the frontend.
*   `months-generated-values.json`: An older, pre-existing data file. It is not currently used by the main application flow.
*   `table-data.json`, `table-data-4.json`: Other example data files. These are not currently used by the main application flow.
*   `README.md`: This file, providing an overview of the project.
